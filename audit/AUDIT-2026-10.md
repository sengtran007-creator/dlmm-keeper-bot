# dlmm-keeper-bot money-path audit, Oct 2026 (main @ ae5242d)

Audit only. No code paths changed; fixes ship one at a time, each with Peter's approval. On-chain evidence comes from
read-only public RPC. Rehearsal evidence comes from `rehearsal/` (the real bot against a local validator with the
mainnet DLMM program and the 4bps pool cloned; throwaway keys).

Severity: **Critical** = can lose funds or disable stops · **High** = wrong accounting or stuck/idle funds ·
**Medium** · **Low**.

### Gate inventory (H0 class: "the gate blocks the action that would satisfy it")
| Path | Gate | Deadlock? |
|---|---|---|
| Deploy USDC→SOL rebalance (TP redeploy, flat boot, re-entry) | swap gate native ≥ 0.125 | **Yes (H0, live)** |
| Deploy sizing holdback deficit | `buyUsd = targetAsk` ignores the deficit | **Yes (H0)**: ask underfilled or "below gas reserve + open cost" throw |
| Top-up USDC→SOL | swap gate 0.125, then `ensureGasReserve(5M)` | **Yes (H3)** while native < 0.125 (post-open 0.12499) |
| Deploy create | `ensureGasReserve(5M)` after `solBal ≥ holdback` (≥ 0.1824) | No |
| Recenter redeploy (SOL-heavy) | SOL→USDC swap, native large | No |
| Fee-SOL swap (sweep) | amount ≤ native − reserve − margin, then swap gate | No (falls back to native transfer) |
| CB / emergency SOL dump | native large after close; close uses fee floor | No (but see L1) |
| Close / claim / withdraw_pct | TX_FEE_FLOOR 0.01 | No |
| transfer_out | floor = reserve + margin + fee | No (refuses; doesn't loop) |

### Checked and OK
- Close retry: chain re-read before each retry. 100% withdraw can't double-withdraw. CLOSE rows only for landed sigs (rehearsal: CLOSE rows = tx meta to the lamport, minus the 5,000-lamport fee; fixed vs the Oct 9 "+0/+0" row).
- Fee claim + sweep: FEE_SWEEP USDC/SOL rows = revenue-wallet deltas exactly (rehearsal, 3 cycles). Mainnet Oct 11 14:16: claim 0.004560777 SOL → native sweep 0.004560777. Fees are counted once (FEE_CLAIM only).
- Claim retry only when provably not landed. A fee-SOL swap with unknown status → no native resend.
- Catch-up sweep is idempotent via the on-chain memo scan. Sweep destination comes from config only (poisoning-safe).
- Gas holdback (ae5242d): native after open = 0.124990 in all rehearsal opens. Open cost = position rent + 0 bin arrays (quote).
- Read guards: spot/equity vetting, fail-closed tick, re-attach after a failed close keeps stops (rehearsal (a): reboot re-attached, single position).
- /transfer_out: allow-list + chat/user gate + paused + quote/confirm code + revalidation + memo; caps $ and % of equity.
- RPC: tick = 1 batched getMultipleAccounts; discovery gPA every POSITION_DISCOVERY_SEC (see rpc-credit-diet).

## Part 3: proposed runtime invariant alerts (not built)
Telegram (bot) plus the health monitor (log-based), each with a de-dup window:
- **GAS_LOW_AFTER_OPEN**: native < GAS_RESERVE within 60 s after a DEPLOY/TOPUP (bot already logs a WARNING; promote to Telegram). Health monitor: regex `native SOL .* < reserve .* after open`.
- **EQUITY_JUMP**: |Δequity| between consecutive good ticks > max($3, 1.5% + 1.2 × |Δspot%| × equity) with no DEPLOY/CLOSE/SWEEP/TOPUP/TRANSFER row in the window. Catches mispriced reads, missed rent, or external transfers. Include the ledger reason codes.
- **CREDIT_SPIKE**: hourly `[RPC]` line > 2× the trailing 24 h median, or est/day > 40k per bot, or combined Helius usage pace > 1M/cycle. Health monitor parses `[RPC] … (≈N/day)`.
- **IDLE_FUNDS**: flat (no position) with wallet > $50 above reserve for > 10 min, or > 15 min with any SOL above reserve (the C1 state). Repeat every 30 min.
- **STOPS_BLIND**: keep the existing 5-min watchdog, and extend it to (a) flat-with-SOL, (b) PAUSED with an open position (every 30 min), (c) no completed tick for 2 min (tick heartbeat timestamp exported to the log every 5 min for the health monitor).
- **ORPHAN_POSITION**: discovery finds a position of this wallet that isn't the active one (today only a console warn).
- **LEDGER_DRIFT** (daily): Σ FEE_SWEEP vs revenue-wallet inflows from the bot wallet; Σ DEPLOY/CLOSE legs vs wallet deltas. Alert if drift > $0.50.
